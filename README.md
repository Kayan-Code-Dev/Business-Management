# نظام إدارة المشاريع الأكاديمية / الخدمية (Business Management)

نظام داخلي متكامل لإدارة المشاريع الأكاديمية والخدمية: العملاء، المختصون، المشاريع، المالية، التقارير، المستخدمون والصلاحيات. واجهة عربية بالكامل (RTL) مبنية وفق وثيقة المتطلبات (BRD + Functional Specification).

## الميزات الرئيسية

- **لوحة تحكم** بمؤشرات تشغيلية ومالية فعلية + تنبيه المشاريع المتأخرة + آخر النشاطات.
- **المشاريع**: إنشاء/تعديل، رحلة حالات واضحة (جديد → مكتمل) مع احتساب "متأخر" تلقائياً، نسبة إنجاز، بحث وفلاتر، ربط أكثر من مختص، رفع ملفات (عميل/مختص)، ملاحظات، ودفعات.
- **العملاء**: قائمة + ملف تفصيلي يعرض مشاريع العميل وسجل دفعاته وأرصدته.
- **المختصون**: قائمة + ملف يعرض المهام، نسبة الالتزام، التكاليف والمستحقات.
- **المالية**: نظرة عامة، سجل العمليات، مستحقات العملاء والمختصين، المصروفات التشغيلية، واحتساب **المتبقي والربح تلقائياً**.
- **التقارير**: تقارير مشاريع/مالية/مختصين/عملاء/عمليات مع فلتر فترة (اليوم/الأسبوع/الشهر/السنة/مخصص) و**تصدير Excel** و**طباعة/PDF**.
- **المستخدمون والأدوار**: 5 أدوار جاهزة + محرر صلاحيات تفصيلي (عرض/إضافة/تعديل/حذف لكل وحدة) مع إخفاء الصفحات والأزرار غير المسموحة.
- **سجل النشاطات**: تسجيل كل العمليات المهمة.
- **الإعدادات**: بيانات المؤسسة، القوائم القابلة للإعداد (أنواع الخدمات، التخصصات، المهارات...)، الإشعارات، ونسخة احتياطية.

## البنية التقنية

| الجزء | التقنية |
|------|---------|
| الخادم (Backend) | Node.js + Express + TypeScript |
| قاعدة البيانات | SQLite عبر Prisma ORM (قابلة للتحويل إلى PostgreSQL) |
| المصادقة | JWT + bcrypt |
| الواجهة (Frontend) | React + Vite + TypeScript + Tailwind CSS (RTL) |
| تصدير Excel | exceljs |

```
.
├── server/   # واجهة برمجية REST (Express + Prisma)
└── client/   # واجهة المستخدم (React + Vite + Tailwind)
```

## التشغيل

### المتطلبات
- Node.js 18+ (تم الاختبار على 22)

### 1) تشغيل الخادم
```bash
cd server
npm install
cp .env.example .env        # عدّل JWT_SECRET في الإنتاج
npx prisma db push          # إنشاء قاعدة البيانات
npm run seed                # بيانات أولية + مستخدمون تجريبيون
npm run dev                 # يعمل على http://localhost:4000
```

### 2) تشغيل الواجهة
```bash
cd client
npm install
npm run dev                 # يعمل على http://localhost:5173
```
الواجهة تمرّر طلبات `/api` تلقائياً إلى الخادم (proxy).

### تشغيل الإنتاج (نشر موحّد)
```bash
cd client && npm install && npm run build   # ينتج client/dist
cd ../server && npm install && npm run build && npm run seed && npm start
# افتح http://localhost:4000 (الخادم يخدم الواجهة المبنية)
```

| المستخدم | الدور | الصلاحيات |
|---------|------|-----------|
| `admin` | مدير النظام | كل الصلاحيات |

| `specialist` | المختص | مشاريعه المرتبطة فقط (بدون بيانات العملاء/الأرباح) |

## قواعد العمل المطبّقة

- المشروع يصبح **متأخراً** تلقائياً إذا تجاوز موعد التسليم ولم يكن مكتملاً/ملغياً.
- **المتبقي على العميل** = قيمة المشروع − إجمالي دفعات العميل.
- **المتبقي للمختص** = التكلفة المتفق عليها − إجمالي المدفوع له.
- **صافي الربح** = دفعات العميل − دفعات المختصين − المصروفات.
- لا يمكن حذف مشروع له دفعات أو ملفات (يُفضّل الأرشفة).
- كل عملية مهمة تُسجّل في سجل النشاطات.
- الصفحات والأزرار غير المسموح بها **مخفية** بحسب صلاحيات الدور.
